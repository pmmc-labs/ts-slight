# Steps for the machine
<!----------------------------------------------------------------------------->

## Code Evaluation 

- JUST
    - return values and constants
- EVAL
    - evaluate things
- APPLY
    - apply procedures
- COND
    - conditional execution

## Interpreter Meta Services

- LOAD/STORE/MOVE
    - heap memory operations
- DEFINE/LET
    - definitions and lexicals
- REQUIRE/USE
    - reading code/loading code
- SYSCALL
    - call system things
- HALT
- ERROR
    - terminals 

## Process control

- FORK
- CONNECT
    - spawn new proceses
- SEND/RECV
    - send/recieve messages
- YIELD
- BLOCK
    - give up control
- JOIN
    - wait on a process
- DISCONNECT
    - disconnect a process
- KILL
    - kill a process
